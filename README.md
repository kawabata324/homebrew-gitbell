# Kawabata324 Gitbell

## How do I install these formulae?

`brew install kawabata324/gitbell/<formula>`

Or `brew tap kawabata324/gitbell` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "kawabata324/gitbell"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
